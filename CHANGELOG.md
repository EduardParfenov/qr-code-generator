# Changelog

История изменений проекта. Формат: [Семантическое версионирование](https://semver.org/lang/ru/).

## [1.2.0] - 2026-09-21

### Добавлено

- Серверная валидация формы: обязательные поля (ФИО, должность, email, рабочий телефон) проверяются на непустоту, email — на простой формат. При ошибках страница возвращается со статусом HTTP 400 и человекочитаемым сообщением со всеми ошибками; раньше такие запросы падали с HTTP 500.
- 8 новых тестов на валидацию (всего 17).

## [1.1.1] - 2026-09-21

### Добавлено

- Тесты на pytest (`tests/test_app.py`): юнит-тесты `generate_vcard`, `generate_qr_code`, `create_business_card` и smoke-тесты роутов Flask. Запуск: `pip install -r requirements-dev.txt && python -m pytest`.

## [1.1.0] - 2026-09-18

### Добавлено

- Настройки компании (название, сайт, адрес) и параметры QR-кода (позиция, размер) вынесены из `app.py` в файл `.env` (переменные окружения через `python-dotenv`).
- Предзаполненные значения полей формы (домен email, шаблон рабочего телефона) вынесены из `templates/index.html` в `.env` (`FORM_EMAIL_DEFAULT`, `FORM_WORK_PHONE_DEFAULT`).
- `.env.example` с демо-значениями и комментариями; `.env` добавлен в `.gitignore`.
- При отсутствии `.env` используются встроенные демо-значения — поведение по умолчанию не изменилось.

## [1.0.1] - 2026-09-18

### Исправлено

- Падение приложения при запуске с `FileNotFoundError`, если отсутствует папка `logs/` (она в `.gitignore` и отсутствует в свежем клоне). Папка создаётся автоматически при старте.

## [1.0.0] - 2026-09-18

### Добавлено

- Инфраструктура для работы через OpenSpec: `AGENTS.md`, `VERSION`, `CHANGELOG.md`, `backlog.md`, заполненный `openspec/config.yaml`.
- Базовые спецификации текущих возможностей приложения (change `bootstrap-project`).
- Папка `input/` добавлена в `.gitignore` (вспомогательные данные, не коммитятся).

## [0.1.0] - до 2026-09-18

Первая рабочая версия (по git-истории).

### Добавлено

- Веб-приложение на Flask: форма ввода контактных данных.
- Генерация vCard (`vobject`) с именем, должностью, email, телефонами, адресом и сайтом.
- Генерация QR-кода (`qrcode`) и наложение на фоновое изображение (`Pillow`).
- Предпросмотр, скачивание PNG и печать из браузера.
- Логирование созданных vCard в `logs/info.log`.
