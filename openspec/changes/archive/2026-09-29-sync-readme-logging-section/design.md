## Context

См. proposal.md — Why. Текущее состояние: `readme.md` раздел «Логирование» (строка 217) утверждает, что в лог пишется полный текст каждой созданной vCard. Реальный код (`app.py:91`) логирует только имя контакта:

```python
logging.info(f"Создана vCard для: {name}")
```

## Goals / Non-Goals

**Goals:**
- Привести раздел «Логирование» в `readme.md` в соответствие с реальным поведением кода.

**Non-Goals:**
- Изменение логирования в коде.
- Исправление других разделов readme.md.
- Обновление `openspec/config.yaml`.

## Decisions

**Решение:** Заменить текст «Приложение пишет логи (включая полный текст каждой созданной vCard) в stdout» на описание реального поведения: в лог пишется только имя контакта (Ф.И.О.) без персональных данных (email, телефоны, адрес).

**Альтернатива:** Изменить код, чтобы логировать полный текст vCard — отклонено, так как это противоречит политике конфиденциальности (ПДн не должны попадать в логи).

## Risks / Trade-offs

- **Риск:** Нет. Изменение только в документации, код не затрагивается.
