## Why

Раздел «Логирование» в `readme.md` противоречит коду: документация утверждает, что в лог пишется полный текст каждой созданной vCard, тогда как `app.py` логирует только имя контакта (без ПДн). Нужно привести документацию в соответствие с реальным поведением.

## What Changes

- Исправить раздел «Логирование» в `readme.md`: убрать упоминание «полный текст каждой созданной vCard», заменить на описание реального поведения — в лог пишется только имя контакта (Ф.И.О.) без персональных данных (email, телефоны, адрес).
