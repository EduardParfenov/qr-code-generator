## Context

См. proposal.md — Why. Текущее состояние: `vobject` сериализует vCard 3.0 в UTF-8 без явного `CHARSET=UTF-8` в полях. Старые телефоны могут не распознать кириллицу.

## Goals / Non-Goals

**Goals:**
- Добавить явный `CHARSET=UTF-8` к текстовым полям vCard для совместимости со старыми телефонами.

**Non-Goals:**
- Модификация структуры vCard.
- Изменение полей vCard.

## Decisions

**Решение:** Использовать встроенную поддержку `vobject` для добавления `CHARSET=UTF-8` к текстовым полям (FN, TITLE, ADR). В vobject это делается через установку параметра `encoding_param` или через `charset_param` у соответствующих свойств.

**Альтернатива:** Ручное форматирование строки vCard — отклонено, так как `vobject` уже предоставляет API для этого.

## Risks / Trade-offs

- **Риск:** Нет. Добавление `CHARSET=UTF-8` не ломает существующие тесты и не меняет структуру vCard.
