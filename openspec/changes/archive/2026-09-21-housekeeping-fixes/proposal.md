# Proposal: housekeeping-fixes

## Why

Серия мелких накопившихся правок из backlog (п.5, 6, 9, 10, 11): пустые телефоны мусорят в vCard, параметры запуска захардкожены, версия Python не зафиксирована, лог растёт бесконечно, а в коде валяется «осиротевшая» строка `Flask`. Каждая правка мала, вместе — заметное наведение порядка.

## What Changes

- **П.6:** пустые добавочный и мобильный телефоны больше не попадают в vCard — поле `TEL` добавляется только при заполненном значении.
- **П.9:** параметры запуска (`debug`, `host`, `port`) читаются из `.env` (`FLASK_DEBUG`, `FLASK_HOST`, `FLASK_PORT`) с прежними дефолтами (`true` / `127.0.0.1` / `5000`).
- **П.11:** ротация лога — `RotatingFileHandler`, максимум 1 МБ на файл, 3 архивных копии.
- **П.5:** удаляется «осиротевшая» строка `Flask` в `app.py` (без влияния на поведение).
- **П.10:** добавляется `.python-version` (3.11.1).

## Capabilities

### New Capabilities

_(пусто)_

### Modified Capabilities

- `vcard-generation`: пустые необязательные телефоны не включаются в vCard (п.6); лог-файл ротируется по размеру (п.11).
- `web-interface`: параметры запуска сервера задаются переменными окружения (п.9).

П.5 (мёртвый код) и п.10 (версия Python) — tooling, дельт спек не требуют.

## Impact

- **Код:** `app.py` — условия добавления телефонов, `RotatingFileHandler`, чтение `FLASK_*` из окружения, минус строка `Flask`.
- **Новые файлы:** `.python-version`.
- **Изменённые файлы:** `.env.example` (3 новые переменные), `readme.md`, `AGENTS.md`, `tests/test_app.py`.
- **Версия:** 2.0.0 → 2.1.0.

## Не входит в объём (Non-goals)

- П.8 (кнопка «Шаблоны визиток») — отдельный change позже.
- Конфигурирование параметров ротации через `.env` (значения 1 МБ × 3 зашиты в коде — достаточно).
- Строгая валидация `FLASK_PORT` (некорректное значение упадёт с явной ошибкой при старте).
