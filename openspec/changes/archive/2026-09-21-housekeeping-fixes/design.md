# Design: housekeeping-fixes

## Context

Пять независимых мелких правок из backlog. Две меняют spec-поведение (п.6, п.9), одна уточняет поведение логирования (п.11), две — tooling (п.5, п.10). См. proposal.md — Why.

## Goals / Non-Goals

**Goals:**

- vCard без пустых полей `TEL`.
- Параметры запуска — из `.env`, прежние дефолты.
- Лог ограничен по размеру, мёртвый код убран, версия Python зафиксирована.
- Все правки покрыты тестами, где это имеет смысл.

**Non-Goals:**

- П.8, конфигурирование ротации, валидация `FLASK_PORT`.

## Decisions

1. **Один change на пять правок.** Каждая тривиальна; пять отдельных changes — бюрократия без выигрыша. Общая версия 2.1.0 (максимальная из категорий: новое поведение).
   _Альтернатива:_ пять changes — отвергнута как избыточная.

2. **П.6 — условия `if ext_phone:` / `if mobile:` в `generate_vcard()`.** Значения уже приходят почищенными (`strip()` в роуте), пустая строка — falsy. Рабочий телефон обязателен (валидируется), его условие не нужно.

3. **П.9 — `FLASK_DEBUG` / `FLASK_HOST` / `FLASK_PORT`.** Префикс `FLASK_` — понятное пространство имён, не конфликтует с COMPANY_*/FORM_*. `FLASK_DEBUG` — строка `"true"`→bool (`true`/`1`/`yes`, регистронезависимо), дефолт `true` (как сейчас); `FLASK_PORT` — `int()`, дефолт 5000. Дефолты сохраняют текущее поведение локального запуска.

4. **П.11 — `RotatingFileHandler(maxBytes=1_000_000, backupCount=3)`.** Штатный класс `logging.handlers`; 1 МБ × 3 архива (`info.log.1` … `info.log.3`) — достаточно для аудита vCard. Значения в коде, не в `.env` (см. Non-goals).

5. **П.10 — `.python-version` = `3.11.1`** (версия из pyenv автора, под ней приложение проверено). Формат понимают pyenv и GitHub Actions.

## Risks / Trade-offs

- [Старые vCard в логе имели пустые TEL — расхождение формата] → Незначимо: лог — аудит, а не API.
- [`.python-version` у кого-то потребует 3.11.1, которой нет] → Мягкое ограничение pyenv, игнорируется без pyenv; readme укажет 3.11+.
- [Ротация удалит старые логи при переполнении] → Осознанно, в этом и смысл; 3 архива — буфер.

## Migration Plan

1. Обновиться до 2.1.0, `pip install -r requirements.txt` (зависимости не менялись).
2. Опционально добавить `FLASK_DEBUG`/`FLASK_HOST`/`FLASK_PORT` в свой `.env` (без них — прежние дефолты).
3. Откат — revert коммита.
