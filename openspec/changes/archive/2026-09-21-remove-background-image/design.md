# Design: remove-background-image

## Context

`create_business_card()` открывает белый квадрат `static/white_page_square.png`, кладёт белую подложку и QR в позицию 0.055/0.055. QR от `qrcode` сам чёрный по белому с тихой зоной. См. proposal.md — Why.

## Goals / Non-Goals

**Goals:**

- Итоговое изображение — чистый QR-код, без композиции.
- Минус ассет, минус 3 настройки, минус код наложения.
- Сканируемость не страдает (тихая зона `border=4` сохраняется).

**Non-Goals:**

- Возврат фирменного фона (отдельный change, если понадобится).
- Тюнинг размера QR (`box_size`) — выходит за объём.

## Decisions

1. **`create_business_card()` сводится к `generate_vcard` + `generate_qr_code`.**
   Имя функции сохраняется (её вызывает роут и тесты), реализация — две строки. Без resize: QR возвращается в натуральном размере (`box_size=10` × число модулей) — для vCard это ~500–800px, достаточно для экрана и печати.
   _Альтернатива:_ удалить функцию, вызывать две из роута — отвергнута: лишний churn в роуте и тестах.

2. **PIL-импорт удаляется из `app.py`.**
   После упрощения `Image`/`ImageDraw`/`ImageFont` не используются. Pillow остаётся в `requirements.txt` — это зависимость `qrcode`.
   `PilImage.save()` от qrcode поддерживает сохранение в буфер — `card.save(buffered, format="PNG")` работает без изменений.

3. **Тихая зона не компенсируется.**
   Раньше была белая подложка +10px; теперь — штатный `border=4` (4 модуля ≈ 40px при `box_size=10`), этого достаточно по стандарту QR.

4. **Переменные `QR_*` из существующих `.env` игнорируются, а не ломают запуск.**
   Код просто перестаёт их читать — миграция пользователя: удалить 3 строки из `.env` (необязательно).

## Risks / Trade-offs

- [Пользователь с кастомным фоном потеряет эту возможность] → Принято: фича не использовалась (фон белый); возврат — через git-историю + новый change.
- [QR без подложки на тёмном CSS-фоне хуже сканируется] → Область предпросмотра светлая; тихая зона QR даёт белую рамку.

## Migration Plan

1. Обновиться до 2.0.0.
2. Удалить `QR_X_POS`, `QR_Y_POS`, `QR_SIZE_RATIO` из своего `.env` (опционально — игнорируются).
3. Откат: `git revert` коммита.
