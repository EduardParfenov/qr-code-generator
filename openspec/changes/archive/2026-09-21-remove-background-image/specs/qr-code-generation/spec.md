## MODIFIED Requirements

### Requirement: Генерация QR-кода из vCard

Система ДОЛЖНА (SHALL) кодировать сериализованную vCard в QR-код с уровнем коррекции ошибок L и автоматическим подбором версии (размера) под объём данных. QR-код ДОЛЖЕН (MUST) быть чёрным по белому фону с тихой зоной (border) вокруг. Итоговое изображение ДОЛЖНО (MUST) быть чистым QR-кодом — без наложения на фоновые изображения.

#### Scenario: QR-код сканируется телефоном

- **WHEN** система сгенерировала QR-код из данных vCard
- **THEN** камера смартфона распознаёт QR-код как контакт (vCard) и предлагает сохранить его в адресную книгу

#### Scenario: Итоговое изображение доступно как PNG

- **WHEN** QR-код сгенерирован
- **THEN** результат сериализуется в формат PNG и передаётся на страницу в кодировке base64

## REMOVED Requirements

### Requirement: Композиция QR-кода с фоновым изображением

**Reason**: Фоновое изображение — белый квадрат; QR-код сам по себе чёрный по белому с тихой зоной, композиция не добавляла ничего, но требовала ассет, три настройки и код наложения.

**Migration**: Настройки `QR_X_POS`, `QR_Y_POS`, `QR_SIZE_RATIO` удалены — при наличии в `.env` они игнорируются. Выводится чистый QR-код; предпросмотр, скачивание и печать работают без изменений.
