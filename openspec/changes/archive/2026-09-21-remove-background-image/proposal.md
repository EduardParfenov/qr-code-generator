# Proposal: remove-background-image

## Why

QR-код накладывается на фон `static/white_page_square.png`, но фон — просто белый квадрат, а QR-код уже чёрный по белому с тихой зоной. Композиция ничего не даёт, но тянет за собой ассет, три настройки (`QR_X_POS`, `QR_Y_POS`, `QR_SIZE_RATIO`) и код наложения. Удаление упрощает приложение без потери функциональности.

## What Changes

- **BREAKING:** удаляется композиция QR с фоном — выводится чистый QR-код (чёрный по белому, с тихой зоной `border=4`).
- **BREAKING:** удаляются настройки `QR_X_POS`, `QR_Y_POS`, `QR_SIZE_RATIO` (из кода, `.env.example`, readme) — если они заданы в существующем `.env`, они просто игнорируются.
- Удаляется ассет `static/white_page_square.png`.
- `create_business_card()` упрощается до «vCard → QR-код».
- Обновляются readme и AGENTS.md (упоминания фона и настроек позиции).

### Modified Capabilities

## Impact

- **Код:** `app.py` — упрощение `create_business_card()`, удаление констант и PIL-импорта.
- **Удаляемые файлы:** `static/white_page_square.png`.
- **Изменённые файлы:** `.env.example` (минус 3 переменные), `readme.md`, `AGENTS.md`, `tests/test_app.py` (тест размера фона заменяется).
- **Версия:** 1.3.0 → **2.0.0** (breaking changes).
- **Пользователям с `.env`:** переменные `QR_*` можно удалить, они игнорируются; предпросмотр/скачивание/печать работают как раньше.

## Не входит в объём (Non-goals)

- Фирменный фон/бланк визитки в будущем (если понадобится — отдельный change, код композиции есть в git-истории).
- Изменение размера/плотности самого QR (`box_size`, `border`) — остаются как в коде.
- Стилизация области предпросмотра через CSS (она уже светлая).
