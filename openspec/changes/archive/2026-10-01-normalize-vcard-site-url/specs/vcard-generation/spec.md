## ADDED Requirements

### Requirement: Поле URL содержит полный URI

Система ДОЛЖНА (SHALL) записывать в поле `URL` vCard значение с полным URI,
как того требует RFC 2426. Если значение `COMPANY_SITE` содержит схему
(`http://`, `https://` или иную), система ДОЛЖНА (MUST) сохранять её без
изменений: решение о выборе схемы остаётся за настройкой приложения. Если схема
отсутствует, система ДОЛЖНА (MUST) добавить `https://` перед значением, чтобы
адрес получателя был полным URI, а не голым доменом.

Система НЕ ДОЛЖНА (MUST NOT) выполнять сетевых запросов при формировании vCard:
проверка достижимости сайта не выполняется, поэтому генерация vCard ДОЛЖНА (MUST)
работать без доступа в интернет.

Пустое значение `COMPANY_SITE` система ДОЛЖНА (MUST) оставлять пустым: поле
`URL` не заполняется, и схема к пустой строке не добавляется. Значение без
содержимого не должно превращаться в `https://`.

Добавление схемы НЕ ДОЛЖНО (MUST NOT) менять домен, его набор символов и
кодировку: кириллический домен в `URL` ДОЛЖЕН (MUST) переживать разбор обратно
парсером наравне с прочими полями vCard.

#### Scenario: В настройке схема отсутствует

- **WHEN** `COMPANY_SITE` задан без схемы (например, `www.gipvn.ru`)
- **THEN** поле `URL` vCard содержит `https://www.gipvn.ru` — полный URI,
  а не голый домен

#### Scenario: В настройке схема указана

- **WHEN** `COMPANY_SITE` задан со схемой (`https://www.gipvn.ru`,
  `http://www.gipvn.ru`)
- **THEN** поле `URL` vCard содержит значение ровно как задано в настройке,
  без добавления и замены схемы

#### Scenario: Указана схема, отличная от HTTPS

- **WHEN** `COMPANY_SITE` задан со схемой, отличной от HTTPS
- **THEN** система сохраняет указанную схему без подмены на `https://`

#### Scenario: Настройка пуста

- **WHEN** переменная `COMPANY_SITE` не задана или задана пустым значением
- **THEN** поле `URL` не заполняется, а значение `https://` в него не попадает

#### Scenario: Кириллический домен переживает round-trip

- **WHEN** `COMPANY_SITE` содержит кириллический домен без схемы
  (например, `рога-и-копыта.рф`)
- **THEN** поле `URL` содержит `https://` и исходный домен без изменения символов,
  и vCard разбирается обратно парсером с тем же значением

#### Scenario: Генерация не зависит от доступности сайта

- **WHEN** адрес из `COMPANY_SITE` не разрешается или недоступен по сети
- **THEN** vCard формируется как обычно, без задержки и без ошибки: система
  не обращается к сайту при генерации
