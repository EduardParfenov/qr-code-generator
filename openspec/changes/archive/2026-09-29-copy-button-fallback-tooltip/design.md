## Context

См. proposal.md — Why. Текущее состояние: `static/main.js:75` при недоступном Clipboard API выполняет `return` без уведомления пользователя.

## Goals / Non-Goals

**Goals:**
- Показать подсказку при недоступном Clipboard API.

**Non-Goals:**
- Настроить HTTPS.
- Добавить JS-тесты.

## Decisions

**Решение:** При `!navigator.clipboard || !window.ClipboardItem` показать существующую всплывающую подсказку с текстом «Скопируйте через правый клик по изображению» на 2 секунды (переиспользуем существующий tooltip-элемент).

**Альтернатива:** Создать отдельный элемент для ошибки — отклонено, переиспользование существующего tooltip проще и не требует изменений в HTML/CSS.

## Risks / Trade-offs

- **Риск:** Нет. Изменение только в JS, backend не затрагивается.
