## Why

При запуске через Docker за nginx без HTTPS кнопка «Копировать» не работает: Clipboard API требует secure context (HTTPS или localhost). Сейчас при недоступном API обработчик молча выходит — пользователь не понимает, что произошло. Нужно показать подсказку.

## What Changes

- В `static/main.js` добавить fallback: при недоступном Clipboard API показывать всплывающую подсказку «Скопируйте через правый клик по изображению» на 2 секунды вместо молчаливого выхода.
