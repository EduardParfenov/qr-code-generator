# web-interface Specification Delta

## MODIFIED Requirements

### Requirement: Форма ввода контактных данных

Система ДОЛЖНА (SHALL) отображать на главной странице (GET `/`) форму с полями: ФИО, должность, email, рабочий телефон, добавочный телефон, мобильный телефон. Поля ФИО, должность, email и рабочий телефон ДОЛЖНЫ (MUST) быть обязательными (HTML5-атрибут `required`) и помечаться индикатором обязательности — звёздочкой `*` в подписи поля. Звёздочка ДОЛЖНА (MUST) отображаться красным цветом, отличным от цвета текста подписи, и НЕ ДОЛЖНА (MUST NOT) быть частью текста подписи (рисуется стилями, чтобы не зачитывалась скринридерами как часть имени поля — обязательность сообщает атрибут `required`). Поле email ДОЛЖНО (MUST) иметь тип `email`, поля телефонов — тип `tel`.

Предзаполненные значения полей email и рабочего телефона ДОЛЖНЫ (MUST) читаться из переменных окружения `FORM_EMAIL_DEFAULT` и `FORM_WORK_PHONE_DEFAULT` (загружаемых из файла `.env` при его наличии). Если переменная не задана, система ДОЛЖНА (MUST) использовать встроенные демо-значения по умолчанию (`@roga-i-kopyta.com` и `+7(800)000-00-00`). Предзаполненные значения ДОЛЖНЫ (MUST) отображаться и после отправки формы (POST `/generate`).

Заглушка «Здесь появится ваш QR-код» в области предпросмотра ДОЛЖНА (MUST) располагаться на одном вертикальном уровне с надписью «Заполните форму» над формой: обе надписи являются первыми элементами своих колонок без дополнительных верхних отступов у одной из них.

#### Scenario: Открытие главной страницы

- **WHEN** пользователь открывает главную страницу приложения
- **THEN** отображается форма с шестью полями и подсказкой, какие поля обязательны, а в области предпросмотра — заглушка «Здесь появится ваш QR-код»

#### Scenario: Красный индикатор обязательности

- **WHEN** пользователь открывает главную страницу приложения
- **THEN** у подписей обязательных полей (ФИО, должность, email, рабочий телефон) отображается красная звёздочка, а у подписей необязательных полей (добавочный и мобильный телефон) звёздочки нет

#### Scenario: Заглушка предпросмотра на одном уровне с заголовком формы

- **WHEN** пользователь открывает главную страницу приложения (QR-код ещё не сгенерирован)
- **THEN** надписи «Заполните форму» (левая колонка) и «Здесь появится ваш QR-код» (правая колонка) начинаются на одном вертикальном уровне

#### Scenario: Отправка формы без обязательного поля

- **WHEN** пользователь пытается отправить форму, не заполнив обязательное поле
- **THEN** браузер блокирует отправку и указывает на незаполненное поле (встроенная HTML5-валидация)

#### Scenario: Предзаполненные значения из .env

- **WHEN** в `.env` заданы `FORM_EMAIL_DEFAULT` и `FORM_WORK_PHONE_DEFAULT` и пользователь открывает форму
- **THEN** поля email и рабочего телефона предзаполнены значениями из `.env`

#### Scenario: Предзаполненные значения без .env

- **WHEN** файл `.env` отсутствует и пользователь открывает форму
- **THEN** поля email и рабочего телефона предзаполнены встроенными демо-значениями

## ADDED Requirements

### Requirement: Копирование QR-кода в буфер обмена

Система ДОЛЖНА (SHALL) отображать после генерации рядом с кнопками «Скачать» и «Печать» зелёную кнопку «Копировать», которая по клику копирует изображение QR-кода в буфер обмена как PNG средствами Clipboard API браузера. Надписи на кнопках действий ДОЛЖНЫ (MUST) располагаться в одну строку и быть выровнены по центру по горизонтали и вертикали. После успешного копирования система ДОЛЖНА (SHALL) показать у кнопки всплывающую подсказку «QR-скопирован в буфер», автоматически скрывающуюся примерно через 2 секунды. Копирование ДОЛЖНО (MUST) выполняться на клиенте из уже отображаемого на странице изображения, без запросов к серверу и без внешних библиотек. Если Clipboard API недоступен (незащищённый контекст — HTTP вне localhost, либо старый браузер), кнопка НЕ ДОЛЖНА (MUST NOT) показывать подсказку об успехе и НЕ ДОЛЖНА (MUST NOT) ломать остальную страницу; в этом случае копирование остаётся доступным через контекстное меню браузера (правый клик по изображению).

#### Scenario: Успешное копирование

- **WHEN** QR-код сгенерирован и пользователь нажимает «Копировать» в браузере с доступным Clipboard API
- **THEN** PNG-изображение QR-кода попадает в буфер обмена, у кнопки появляется подсказка «QR-скопирован в буфер», которая исчезает примерно через 2 секунды

#### Scenario: Clipboard API недоступен

- **WHEN** страница открыта в окружении без Clipboard API (HTTP вне localhost или старый браузер) и пользователь нажимает «Копировать»
- **THEN** копирование не выполняется, подсказка об успехе не показывается, остальная страница (скачивание, печать) работает как раньше

### Requirement: Высота и выравнивание кнопок действий

Система ДОЛЖНА (SHALL) отображать все кнопки («Сгенерировать QR-код», «Скачать», «Печать», «Копировать», «Перейти в папку "Шаблоны визиток"») одинаковой высоты; эталон — высота кнопки «Сгенерировать QR-код». В двухколоночном макете нижний ряд кнопок правой колонки (ряд с «Перейти в папку "Шаблоны визиток"» при её наличии, иначе ряд «Скачать»/«Печать»/«Копировать») ДОЛЖЕН (MUST) стоять на одном вертикальном уровне с кнопкой «Сгенерировать QR-код» в левой колонке. Изображение QR-кода ДОЛЖНО (MUST) быть отцентрировано по вертикали между надписью «Ваш QR-код, …» и верхним рядом кнопок. Расстояние между рядами кнопок в правой колонке НЕ ДОЛЖНО (MUST NOT) изменяться. Одноколоночный (мобильный) макет НЕ ДОЛЖЕН (MUST NOT) изменяться.

#### Scenario: Кнопки одинаковой высоты

- **WHEN** QR-код сгенерирован
- **THEN** все кнопки на странице имеют одинаковую высоту

#### Scenario: Нижние ряды кнопок на одном уровне

- **WHEN** QR-код сгенерирован, задана `CARD_TEMPLATE_URL` и страница открыта в двухколоночном макете
- **THEN** кнопка «Сгенерировать QR-код» (левая колонка) и ряд с кнопкой «Перейти в папку "Шаблоны визиток"» (правая колонка) стоят на одном вертикальном уровне, а расстояние между рядами кнопок правой колонки остаётся прежним (20px)

#### Scenario: QR-код по центру области результата

- **WHEN** QR-код сгенерирован и страница открыта в двухколоночном макете
- **THEN** изображение QR-кода отцентрировано по вертикали между надписью «Ваш QR-код, …» и верхним рядом кнопок
