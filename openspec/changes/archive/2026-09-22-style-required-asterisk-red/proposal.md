# Предложение: красные звёздочки обязательных полей формы

## Why

Сейчас звёздочки обязательных полей (Ф.И.О.*, Должность*, e-mail*, Тел. рабочий*) отображаются тем же цветом, что и текст подписи (зелёный `#009639`), и визуально не выделяются. Пользователь просит сделать звёздочки красными, чтобы обязательность полей считывалась сразу. Красный индикатор обязательности — общепринятый UI-паттерн.

## What Changes

- Звёздочка обязательного поля отделяется от текста подписи и окрашивается в красный цвет `#d32f2f`.
- Реализация — через CSS `::after` у `label` с классом-маркером обязательности: символ `*` убирается из текста подписей в `templates/index.html`, а отрисовывается стилями в `static/style.css`.
- Цвет задаётся CSS-переменной в `:root` (в духе существующей цветовой схемы).
- Легенда «* - поля обязательные для заполнения» (блок `.attention`) не меняется — она уже целиком красная.
- Заглушка «Здесь появится ваш QR-код» поднимается на один вертикальный уровень с надписью «Заполните форму» (сейчас сдвинута вниз на 25px из-за обёртки `.result` с верхним margin).
- Рядом с кнопками «Скачать» и «Печать» добавляется зелёная кнопка «Копировать» (надписи всех кнопок действий в одну строку, выровнены по центру по обеим осям): копирует PNG-изображение QR-кода в буфер обмена через Clipboard API и показывает всплывающую подсказку «QR-скопирован в буфер» (~2 сек). Копирование выполняется на клиенте из уже отображаемого base64-изображения, без запросов к серверу и внешних библиотек. Фолбэк при недоступном Clipboard API не реализуется (решение пользователя): копирование остаётся доступным через правый клик по изображению.
- Из `static/main.js` удаляется мёртвая функция `copyImageFallback()` (нигде не вызывается) — на её месте появляется рабочая реализация копирования.
- Все кнопки действий приводятся к единой высоте (эталон — кнопка «Сгенерировать QR-код»): единый `line-height` для `<button>` и `<a>`. В десктопном двухколоночном макете нижние ряды кнопок обеих колонок выравниваются по одному уровню (колонки — flex-контейнеры, нижний ряд прижат к низу), а изображение QR-кода центрируется по вертикали между надписью «Ваш QR-код, …» и верхним рядом кнопок. Расстояние между рядами кнопок в правой колонке не меняется; мобильная вёрстка не затрагивается.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `web-interface`: уточняется требование «Форма ввода контактных данных» — индикатор обязательности (звёздочка) ДОЛЖЕН отображаться красным цветом и отделяться от текста подписи; заглушка предпросмотра ДОЛЖНА стоять на одном вертикальном уровне с заголовком формы. Добавляется требование «Копирование QR-кода в буфер обмена».

## Impact

- **Код:** `templates/index.html` (подписи обязательных полей, заглушка предпросмотра, кнопка копирования), `static/style.css` (новое правило и CSS-переменная, стили кнопки и тултипа), `static/main.js` (обработчик копирования, удаление мёртвого кода).
- **Поведение:** только визуальное — цвет звёздочки. Логика формы, валидация и backend не затрагиваются.
- **Зависимости:** не добавляются.
- **Тесты/версия:** `python -m pytest` должен проходить; по конвенциям проекта обновляются `VERSION` и `CHANGELOG.md`.

## Не входит в объём

- Изменение легенды в блоке `.attention` (уже красная).
- Изменение логики валидации, набора обязательных полей, текстов подписей и плейсхолдеров.
- Изменение backend (`app.py`) и JavaScript (`main.js`).
- Общий редизайн формы или переход на CSS-фреймворк.
