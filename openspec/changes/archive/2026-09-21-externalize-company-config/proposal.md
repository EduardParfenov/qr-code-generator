# Proposal: externalize-company-config

## Why

Настройки компании (название, сайт, адрес) и параметры QR-кода (позиция, размер) захардкожены в `app.py`. Чтобы адаптировать приложение под свою компанию, нужно править код — это неудобно и чревато ошибками при обновлениях. Настройки должны жить отдельно от кода.

## What Changes

- Настройки выносятся из `app.py` в файл `.env` (переменные окружения через `python-dotenv`): название организации, сайт, адрес (улица, город, область, индекс, страна), позиция QR (`QR_X_POS`, `QR_Y_POS`), размер QR (`QR_SIZE_RATIO`).
- Значения по умолчанию в полях формы (домен email `@roga-i-kopyta.com`, шаблон рабочего телефона `+7(800)000-00-00`) выносятся из `templates/index.html` в `.env` (`FORM_EMAIL_DEFAULT`, `FORM_WORK_PHONE_DEFAULT`).
- `.env` добавляется в `.gitignore` (локальные данные компании не попадают в репозиторий); в git коммитится `.env.example` с демо-значениями.
- При отсутствии `.env` или отдельных переменных приложение использует встроенные демо-значения по умолчанию — работает «из коробки».
- Новая зависимость: `python-dotenv` (в `requirements.txt`).
- Обновляется раздел «Настройка» в `readme.md`.

### Modified Capabilities

- `vcard-generation`: данные компании (название, сайт, адрес) больше не задаются в коде — берутся из переменных окружения с демо-значениями по умолчанию.
- `qr-code-generation`: позиция и размер QR-кода на фоне задаются переменными окружения с прежними значениями по умолчанию (0.055 / 0.055 / 0.9).
- `web-interface`: значения по умолчанию в полях email и рабочего телефона задаются переменными окружения с прежними демо-значениями по умолчанию.

## Impact

- **Код:** `app.py` — загрузка `.env` при старте, хардкод заменён на чтение переменных окружения с дефолтами.
- **Новые файлы:** `.env.example`.
- **Изменённые файлы:** `.gitignore` (добавлен `.env`), `requirements.txt` (добавлен `python-dotenv`), `readme.md` (раздел «Настройка»), `templates/index.html` (значения полей из переменных).
- **Поведение по умолчанию не меняется:** без `.env` приложение генерирует те же vCard и QR, что раньше.

- Валидация значений конфигурации (например, что `QR_X_POS` в диапазоне 0..1).
