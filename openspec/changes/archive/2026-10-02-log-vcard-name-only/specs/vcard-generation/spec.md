## MODIFIED Requirements

### Requirement: Логирование созданных vCard

Система ДОЛЖНА (SHALL) записывать в стандартный поток вывода (stdout) с уровнем INFO только имя контакта — значение поля `FN` — в виде строки вида `v-card создана для контакта: <ФИО>`. Запись сопровождается меткой времени и кодировкой UTF-8, чтобы логи были доступны через `docker logs` / `docker compose logs` при запуске в контейнере и через консоль при локальном запуске.

Содержимое остальных полей vCard — e-mail (`EMAIL`), рабочий, добавочный и мобильный телефоны (`TEL`), должность с названием организации (`TITLE`), рабочий адрес (`ADR`), сайт компании (`URL`) — НЕ ДОЛЖНО (MUST NOT) попадать в лог ни в каком виде, включая сериализованный текст vCard.

Перед записью в лог из значения имени убираются символы перевода строки: система ДОЛЖНА (MUST) заменять символ перевода строки пробелом, чтобы содержимое поля не могло породить в логе отдельную запись, которой система не создавала.

Имя контакта само является персональными данными: решение оставить его в логе сознательное и ограничено одним полем. Запись в лог-файл и ротация логов на стороне приложения НЕ выполняются: ротацией логов заведует Docker (logging driver).

#### Scenario: Запись vCard в лог

- **WHEN** система успешно сформировала vCard по данным формы
- **THEN** в stdout появляется запись уровня INFO, содержащая имя контакта из поля `FN`

#### Scenario: Остальные поля в лог не попадают

- **WHEN** система сформировала vCard с заполненными e-mail, рабочим, добавочным и мобильным телефонами, должностью, адресом и сайтом компании
- **THEN** в записи лога присутствует имя контакта и НЕ присутствуют значения e-mail, телефонов, должности, адреса, сайта и названия организации

#### Scenario: Сериализованный текст vCard в лог не выводится

- **WHEN** система сформировала vCard
- **THEN** запись лога не содержит ни маркеров vCard (`BEGIN:VCARD`, `VERSION:`, `END:VCARD`), ни имён полей (`FN:`, `EMAIL:`, `TEL:`, `TITLE:`, `ADR:`, `URL:`)

#### Scenario: Перевод строки в имени контакта не создаёт отдельную запись

- **WHEN** в поле ФИО формы передано значение, содержащее символ перевода строки
- **THEN** в логе появляется ровно одна запись об этой генерации, а символ перевода строки заменён пробелом внутри значения имени

#### Scenario: Просмотр логов в контейнере

- **WHEN** приложение запущено в Docker-контейнере и создана vCard
- **THEN** запись видна в выводе `docker logs <контейнер>` / `docker compose logs` с меткой времени

#### Scenario: Ротация при переполнении

- **WHEN** объём логов достигает предела, заданного в настройках logging Docker (в `docker-compose.yml`)
- **THEN** Docker ротирует лог-файлы (старые архивируются, лишние удаляются); приложение ротацию не выполняет и о ней не знает
